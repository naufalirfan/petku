Kebijakan Privasi — Pet Game

Terakhir diperbarui: 14 Oktober 2026

Pet Game adalah game virtual pet offline. Kami menghormati privasi kamu.

Data yang dikumpulkan

  • Tidak ada. Game menyimpan progres (koin, level pet, item) hanya di perangkat via penyimpanan lokal. Tidak dikirim ke server kami.
  • Tidak ada login, tidak ada akun, tidak ada analytic pihak ketiga, tidak ada iklan saat ini.
  • Notifikasi lokal (opsional) dijadwalkan di perangkat saja, tidak butuh internet.

Izin

  • POST_NOTIFICATIONS (Android 13+): untuk pengingat "Pet lapar!" — bisa ditolak, game tetap jalan.
  • INTERNET: dicadangkan untuk update & AdMob masa depan. Saat ini tidak dipakai.

Pihak ketiga

Saat AdMob/IAP diaktifkan nanti, kebijakan ini akan diperbarui dan tautan di Play Console diganti. Versi ini berlaku untuk build tanpa AdMob.

Anak-anak

Game cocok untuk semua umur. Tidak ada chat, tidak ada pembelian tersembunyi di versi tanpa AdMob.
